# Contributing to NetOps AI MOP Auditor

Thank you for your interest in contributing! Whether it's reporting a bug, adding a new MOP maintenance scenario, improving guardrails, or updating documentation, contributions are welcome.

1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/AmazingScenario`).
3. Commit your changes (`git commit -m 'Add MOP-105 scenario'`).
4. Push to the branch (`git origin push feature/AmazingScenario`).
5. Open a Pull Request.
